**1、安装virtualbox**

virtualbox安装的姿势很多，kali之前的版本是可以通过apt-get install virtualbox来安装。

或者去官方网站下载virtualbox stretch版本，官方网站：https://www.virtualbox.org/wiki/Linux\_Downloads，

wget [http://download.virtualbox.org/virtualbox/5.1.10/virtualbox-5.1\_5.1.10-112026](http://download.virtualbox.org/virtualbox/5.1.10/virtualbox-5.1_5.1.10-112026) ~Debian~stretch\_amd64.deb

下载完成以后，通过dpkg安装：

dpkg -i virtualbox-5.1\_5.1.2-108956~Debian~stretch\_i386.deb

如果有缺少依赖文件就使用下面命令补上去：apt-get -f install

[![2016-12-16 11-31-43屏幕截图.png](http://image.3001.net/images/20161218/14820253008345.png%21small)](http://image.3001.net/images/20161218/14820253008345.png%21small)

运行 sudo /sbin/vboxconfig，检查是否缺少内核文件，然后根据提示安装内核文件，如：apt-get install linux-headers-amd64

[![2016-12-16 12-54-16屏幕截图.png](http://image.3001.net/images/20161218/14820253014082.png%21small)](http://image.3001.net/images/20161218/14820253014082.png%21small)[![2016-12-16 12-54-03屏幕截图.png](http://image.3001.net/images/20161218/14820253008524.png%21small)](http://image.3001.net/images/20161218/14820253008524.png%21small)**2、安装packer**

root@kali:/# apt-get install packer

[![2016-12-16 11-17-21屏幕截图.png](http://image.3001.net/images/20161218/14820253009312.png!small)](http://image.3001.net/images/20161218/14820253009312.png)**3、安装vagrant**

wget [https://releases.hashicorp.com/vagrant/1.9.1/vagrant\_1.9.1\_x86\_64.deb](https://releases.hashicorp.com/vagrant/1.9.1/vagrant_1.9.1_x86_64.deb)

dpkg -i vagrant\_1.9.1\_x86\_64.deb

[![2016-12-16 11-20-36屏幕截图.png](http://image.3001.net/images/20161218/14820253005103.png%21small)](http://image.3001.net/images/20161218/14820253005103.png%21small)**4、执行 build\_win2008.sh**

给sh文件加上执行权限：chmod +x build\_win2008.sh，并运行它。 **[![2016-12-16 13-08-49屏幕截图.png](http://image.3001.net/images/20161218/14820253028398.png%21small)](http://image.3001.net/images/20161218/14820253028398.png%21small)** [![2016-12-16 13-09-33屏幕截图.png](http://image.3001.net/images/20161218/14820253033893.png%21small)](http://image.3001.net/images/20161218/14820253033893.png%21small)

在Waiting for SSH to become available是有点慢，耐心等待！这时打开VirtualBox管理器可以看到预览中正在创建虚拟机。当虚拟机安装完之后，安装脚本会自动通过SSH连入虚拟机并进行各种漏洞设置。

[![2016-12-16 13-08-18屏幕截图.png](http://image.3001.net/images/20161218/1482025303879.png%21small)](http://image.3001.net/images/20161218/1482025303879.png%21small)[![2016-12-16 13-13-44屏幕截图.png](http://image.3001.net/images/20161218/14820253048176.png%21small)](http://image.3001.net/images/20161218/14820253048176.png%21small)

build\_win2008.sh 执行结束后会提示你执行vagrant up来启动虚拟机配置：

[![2016-12-16 13-25-09屏幕截图.png](http://image.3001.net/images/20161218/14820253059494.png%21small)](http://image.3001.net/images/20161218/14820253059494.png%21small)**5、执行vagrant up**

第一次执行vagrant up会往虚拟机中安装各种软件，和配置虚拟机中的漏洞。

**6、使用虚拟机**

在上面第一次执行完vagrant up之后就可以正常使用虚拟机了，后面也不用每次都执行vagrant up，直接通过VirtualBox来打开就可以了。
